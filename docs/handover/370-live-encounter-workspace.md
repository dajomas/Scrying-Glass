## Corrective findings and proposal - 2026-11-09

The initial sidebar selectors lost to existing #encounterFeatures rules. Vertical .et-header made the original flex-basis:22rem allocate excess connection-panel height; the two-column tool grid also remained. Corrective selectors include #encounterFeatures so flex:none/natural height and single-column panels/controls win. No fixed connection-panel height is imposed. Only the redundant inner Activity log h2 is hidden; native disclosure/export/clear nodes and behavior remain.

The old serialized feature_summary response deliberately replaced displays with [] for regular admins; frontend interpreted that as zero. Simply removing suppression would expose unfiltered socket metadata. python/scrying_glass_display_status.py instead filters current socket membership through current session/role, existing viewer choices/permissions and explicit campaign selection (or sole-choice automatic selection). Only connections viewing the active authorized campaign appear, including for superadmin summaries. Ownership is rechecked; other campaigns, ambiguous/unselected viewers, revoked grants/sessions and disconnected sockets are excluded. Counts represent socket connections, not unique accounts. Existing live/behind/stale heartbeat classification is preserved; no socket protocol or grants change.

The serialized summary boundary replaces the unfiltered list with scoped metadata plus display_scope_available/display_campaign_id. Missing scope is explicitly unavailable. static/features.js distinguishes unknown/mismatched-campaign/failed refresh from genuine zero; it does not keep a stale count after failure. Existing polling frequency and health/effect mutation behavior remain unchanged. Feature JS and live CSS asset versions are bumped to 2 in the matching template. This is a targeted authorized metadata correction, not a new global viewer directory, schema change or combat-rule change.
